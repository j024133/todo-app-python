# TODOアプリ

## 概要
Pythonで作成したタスク管理アプリです。
タスクの追加、表示、削除、完了状態の切り替えができます。

## 使用技術
- Python

## 機能
- タスク追加
- タスク一覧表示
- タスク削除
- タスク完了状態の切り替え
- タスクデータの保存・読み込み

## 工夫した点
- タスクを tasks.txt に保存し、アプリを終了しても内容が保持されるようにしました。
- 完了したタスクには「✓」を表示し、進捗が分かりやすいようにしました。
- ユーザーが番号を選択するだけで操作できるようにし、シンプルな操作性を意識しました。

## 実行方法

```bash
python todo.py
```
